# 質問内容閲覧機能 設計ドキュメント

- 作成日: 2026-07-24
- ステータス: 設計確定（実装計画はこれから）
- 関連: [MVP設計ドキュメント](2026-07-23-world-history-quiz-design.md)

---

## 1. 背景・目的

現状のアプリはクイズ（4方向スワイプの自己採点）のみで、**問題と解答を一覧で読む手段がない**。
記憶は「想起（クイズ）」の前に「入力（覚える）」のフェーズが必要であり、そこに一覧画面が欠けている。

本機能は、章の問題と解答を上から順に読み下せる**通読画面**を追加する。あわせて、赤シート的に解答を隠して自己確認もできるようにする。

- **主用途**: 章を通し読みして覚える（クイズ前の暗記・教科書/単語帳的な使い方）
- **想定シーン**: これから学ぶ章をひと通り眺める／クイズ前に流し読みする

---

## 2. 導線・ルーティング

- **入口**: 章詳細画面（`/chapter/:chapter`）。既存の「▶ この章を学習」の**上**に「📖 一覧で見る」ボタンを追加する。
- **ルート**: `/chapter/:chapter/questions`
- **タブ構成は変更しない**（ホーム / 成績 / 設定 の3タブのまま）。
- 既存の没入判定（`App.tsx` の `IMMERSIVE` に `/^\/chapter\//` が含まれる）にそのまま該当するため、**フッターは自動的に非表示**になる。追加設定は不要。
- 戻るは左上「‹」で章詳細へ。

> 4つ目のタブとして独立させる案も検討したが、通読は章単位の行為であり章詳細からの導線が自然なため見送った。

---

## 3. 画面レイアウト

コンパクトな行型リスト。1行＝1問。

```
‹  古代オリエント
   30問
 ┌─────────────────────────────┐
 │ 🔒 解答を隠す      │ 絞り込み ▾ │
 └─────────────────────────────┘
 ┌─────────────────────────────┐
 │ ● ラテン語で日の昇るところという意味の   │
 │   エジプトから西アジアにかけての地域の   │
 │   ことを何と言うか                      │
 │                          オリエント │  ← 解答は下・右寄せ
 ├─────────────────────────────┤
 │ ● 川の間地域という意味で…               │
 │                        ▨▨▨▨▨▨ │  ← 伏せ字（全問同じ幅）
 └─────────────────────────────┘
```

- **ヘッダー**: 戻る「‹」／章名／問題数。絞り込み中は「◯問 / 全◯問」と表示する。
- **操作バー**: 一括トグル（`🔒 解答を隠す` ⇄ `🔓 解答を表示`）＋ `絞り込み ▾`。
- **各行**:
  - 左端に習熟度のカラードット（マスター=緑 `#3f9e5a` / あやふや=黄 `#e6b800` / できなかった=赤 `#e5736b` / 未回答=灰 `#c9ccd6`）
  - 問題文は横幅いっぱい（読みやすさ優先）
  - **解答は問題文の下、右寄せ**。アクセント色・太字
  - 伏せ字は**全問共通の固定幅（96px）のグレー帯**とし、右端に揃える
- **並び順**: 常に問題No.順（設定の「出題順（順番/ランダム）」の影響は受けない。通読は章の並びで読むもの）

### 伏せ字を固定幅にする理由

解答の文字数に合わせて幅を変えると、**帯の長さから答えを推測できてしまう**。全問同じ幅にすることでヒントの漏れを防ぐ。

## 4. 振る舞い

| 操作 | 挙動 |
|---|---|
| 初期表示 | **解答は隠れた状態**（実機フィードバックにより変更。暗記用途では最初から見えていると答えが目に入ってしまうため） |
| 一括トグル | 全問の解答を一括で隠す／表示する |
| 個別タップ | 隠している時、行をタップするとその1問だけ表示。再タップで再び伏せる |
| 解答表示中のタップ | **何も起こらない**（すでに見えているため無反応） |
| 一括トグルの押し直し | 個別に開いた状態はすべてリセットされる |
| 絞り込み | 習熟度（マスター／あやふや／できなかった／未回答）の複数選択。既定は全部ON |
| 絞り込み結果が0件 | リストの代わりに「該当する問題がありません」と表示する（絞り込みUIは操作可能なまま） |
| 画面を離れる | トグル・絞り込みの状態は初期化（設定には保存しない） |

### 閲覧専用

**この画面から習熟度は変更しない。** 習熟度はクイズの自己採点でのみ変化する。

理由: クイズを経ずに習熟度を変更できると、「実際に思い出せた割合」という習熟度の意味が薄まり、章の伸びグラフの信頼性も損なわれるため。

## 5. 実装方針

### ファイル構成

| 種別 | パス | 責務 |
|---|---|---|
| 新規 | `src/screens/QuestionListScreen.tsx` | 一覧画面。トグル・個別開閉・絞り込みのUI状態を持つ |
| 新規 | `src/domain/browse.ts` | 絞り込みの純粋関数 |
| 新規 | `src/domain/browse.test.ts` | 上記のテスト |
| 変更 | `src/App.tsx` | ルート `/chapter/:chapter/questions` を追加 |
| 変更 | `src/screens/ChapterDetailScreen.tsx` | 「📖 一覧で見る」ボタンを追加 |

### 再利用するもの

- `useQuestions()` … 問題データ
- `useAppData()` … `data.progress`（習熟度の参照のみ）
- `STATE_COLORS`（`src/domain/colors.ts`）… ドットの色

### データ

**新しい永続データは追加しない。** 表示のみで、`localStorage` のスキーマは変更しない。

### 絞り込み関数

章と選択中の状態集合から、表示対象の問題を返す純粋関数を `browse.ts` に置く。画面側は薄く保つ。

```ts
filterQuestions(questions, progress, chapter, states): Question[]
```

- `states` が空集合の場合は**空配列**を返す（＝「該当なし」を表示する）
- 並びは問題No.昇順

### テスト

- **ドメイン**: `filterQuestions` をTDDで（状態ごとの抽出、未登録=未回答の扱い、空集合、No.順）
- **画面**: コンポーネントテストで「初期は解答が見えている」「一括トグルで隠れる」「隠れている時に行タップで1問だけ出る」「絞り込みで件数が変わる」を検証

## 6. スコープ外（今回入れない）

- キーワード検索
- 章をまたぐ横断閲覧
- 一覧からの習熟度変更
- 読み上げ、単語帳スワイプ、印刷/PDF出力

---

## 7. 検討した代替案

| 案 | 評価 |
|---|---|
| カード型レイアウト（1問=1カード） | 読みやすいが30問だとスクロールが増え俯瞰しづらい → 行型を採用 |
| 解答を右カラムに分離（左:問題 / 右:解答） | 列は揃うが問題文が窮屈になり、長い解答が折り返す → 「下・右寄せ」に落着 |
| 4つ目のタブとして独立 | 常時アクセスできるが、章単位の通読には章詳細からが自然 → 見送り |
| 一覧から習熟度を変更可能にする | 手軽だが習熟度が実力を表さなくなる → 閲覧専用に |

---

## 8. 受け入れ基準

- [ ] 章詳細から「📖 一覧で見る」で一覧画面に遷移でき、「‹」で戻れる
- [ ] その章の全問が No.順 で表示され、初期状態では解答が隠れている
- [ ] 一括トグルで全問の解答が隠れ、再度押すと全問表示される
- [ ] 隠れている状態で行をタップすると、その1問だけ解答が表示される
- [ ] 伏せ字の幅がすべての問題で同一である
- [ ] 習熟度で絞り込むと該当問題だけが表示され、ヘッダーの件数が更新される
- [ ] 一覧画面では習熟度が変化しない（クイズ以外で進捗が動かない）
- [ ] フッター（3タブ）は一覧画面では非表示になる
